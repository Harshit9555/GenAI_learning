# Python Product Collection Operations

This project demonstrates Python data structures and operations using a product catalog in a Jupyter Notebook.

## Tasks Covered

### Task 1: Product Collections (Lists & Tuples)

- Create a `products` list containing at least six product names.
- Create a `sample_product` tuple containing a product name, price, and category.
- Print the second and last products.
- Append two new product names and display the updated list.
- **Optional:** Convert the tuple to a list, update its price, and convert it back to a tuple.

### Task 2: Categories (Sets)

- Create a set of product categories.
- Add a new category and demonstrate that duplicates are ignored.
- Check whether a category exists in the set.
- **Optional:** Count the unique categories.

### Task 3: Product Pricing (Dictionaries)

- Create a `price_dict` containing at least six products and their prices.
- Add a new product and price.
- Update an existing product's price.
- Remove a product by name and handle missing products.
- Calculate the average price.
- **Optional:** Display the products with the maximum and minimum prices.

### Task 4: Combined Operations

- Create a `catalog` list of tuples in the format `(product_name, price, category)`.
- Create a `category_to_products` dictionary mapping categories to product names.
- Display all products belonging to the category with the most products.

## Requirements

- Python 3.8 or newer recommended.
- Jupyter Notebook or JupyterLab.
- No third-party libraries required.

## How to Run

1. Install and open Jupyter Notebook or JupyterLab.
2. Open the `.ipynb` notebook containing the solutions.
3. Run each cell in order using **Run** or **Shift + Enter**.

## Concepts Practiced

- Lists and indexing
- Tuples and tuple conversion
- Sets and unique values
- Dictionaries and key-value operations
- Basic arithmetic and averages
- Grouping products by category
